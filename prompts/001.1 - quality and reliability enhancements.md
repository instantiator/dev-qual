This repository currently contains documentation for coding agents to read, to support them to generate consistently high quality code. Let's create a plan to improve it.

At the moment, the suggested process relies on the agent reading the appropriate documentation and remembering to refresh what it needs to know as it goes about different tasks.

The goal of this task is to produce a plan to implement improved documentation and new skills that can be brought in to each development project. Although this plan is being generated by Fable, it should target _any_ other coding assistant model (eg. those available through OpenCode).

It should anticipate that models have smaller context windows, and are a bit less able to reason - so it should do a lot of the work up front, and condense its information to increase the likelihood that a coding assistant can usefully work with it.

Output from coding assistants should remain human readable, including any code that needs to be written to support this (eg. scripts to help install skills, or perform activities to relieve simpler coding assistant models of cognitive load.)

Whilst simpler models cannot complete "one shot, build the whole thing" tasks (per Fable's reputation), they should be able to complete features, bug-fixes, or improvements to high standards with assurances that the code will work.
